# 🎧 WaveX Music Player

https://abhicodeflex.github.io/wavex-music-player/

WaveX Music Player is a modern web-based music player with a futuristic UI, playlist system, and voice recorder. It is built using HTML, CSS, and JavaScript with advanced features like IndexedDB storage and audio visualization.

---

## 🚀 Features

* 🎵 Music Player with Play/Pause, Next/Previous
* 📂 Playlist Management (Create, Rename, Delete)
* 💾 Local Storage using IndexedDB (No backend required)
* 🎧 Audio Visualizer (Dynamic UI)
* 🔊 Volume Control & Progress Bar
* 🎙 Voice Recorder System
* 📱 Responsive Design
* ⚡ Futuristic UI (Inspired by - Jarvis UI)

---

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript (Vanilla)
* IndexedDB (Browser Database)
* Web Audio API

## ▶️ How to Run

1. Download or clone the repository
2. Open `index.html` in your browser
3. Create a playlist
4. Add songs using the **+ Add** button
5. Click on any track to play

---

## 💡 How It Works

* Songs are stored locally using **IndexedDB**
* No backend is required
* Audio is processed using Web Audio API
* UI updates dynamically based on user interaction
